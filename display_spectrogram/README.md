# Mel Spectrogram Display

The code in this folder does not affect the model. Instead, this code serves to display the Mel spectrogram of a given audio clip. This code is solely for seeing the data which the model is trained on.

## Usage

1. Place a wav audio file in this directory named "audio.wav". 
2. Open a new terminal, and navigate to the directory of the project.
3. Run `python3 display/main.py`
4. After some time, a popup will appear showing the Mel spectrogram of the audio
