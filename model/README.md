# The Model

The model is created and trained within this folder. You must first generate the training data for the model using the code within the `data_conversion` folder. The model will look for the data generated by this code and use it for training. This model uses standard CNN architecture and predicts 5 emotions (anger, happy, neutral, sad, and surprised).

## Usage

1. Follow the instructions for preprocessing the dataset within the `data_conversion` folder. Afterwards, ensure that a folder named `train_data` was created.
2. After generating the training data, the model can be run as using `python3 model/main.py`. This will train a CNN from scratch, so it will take a long time depending on your dataset side and hardware. The model used in the DoSE app took about 30 minutes to train on about 140,000 audio clips on a laptop.
3. After training, the model will be saved to a folder named `model_results` as a .h5 file. The confusion matrix and loss graphs are also created and saved here for your analysis purposes.
